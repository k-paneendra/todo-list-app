# 📝 To-Do List Web Application

A clean, fast, and responsive web application designed to help you organize daily tasks, stay focused, and boost productivity.

🔗 **[Live Demo](https://k-paneendra.github.io/todo-list-app/)**

---

## ✨ Features

- **Task Management**: Quickly add, complete, and delete daily tasks.
- **Persistent Data**: Automatically saves your tasks locally in the browser (`localStorage`), so your data stays intact when you refresh or return later.
- **Clean & Responsive UI**: Designed to work smoothly across desktop, tablet, and mobile browsers.
- **Task Filtering**: Easily toggle between viewing all, active, or completed tasks.
- **Lightweight & Fast**: Built with pure web technologies for instant load times and zero dependency overhead.

---

## 🛠️ Tech Stack

- **HTML5**: Structural layout and accessible forms.
- **CSS3**: Custom styling, layout design, and responsive media queries.
- **JavaScript (ES6+)**: Dynamic task handling, DOM manipulation, and persistent browser storage.
